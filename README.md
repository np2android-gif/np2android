# Neko Project II for Android

PC-9801/PC-9821 シリーズのエミュレーター **Neko Project II**のXへの移植（Xnp2 0.86）を Android に移植したものです。
FDD・HDD・CD-ROM のイメージの処理には **NP2kai** のコードを取り込んでいます。

> これは非公式の移植です。Neko Project II（ねこさん開発ちーむ）、Xnp2、NP2kai の作者の方々とは関係がありません。
> このアプリについての問い合わせは、元の作者の方々にはしないでください。

2012〜2013 年に公開していた「Neko Project II for Android」の後継です（パッケージ名も同じ `jp.sawada.np2android`）。
以前の版と署名が違うため、以前の版が入っている場合は、いったんアンインストールしてから入れてください。

- 対応: Android 7.0 以上（arm64-v8a・x86_64）
- 動作確認: Xperia XZ3（Android 10）、Pixel 9a（Android 17）
- 最新版: v0.86-a6

## インストール

[Releases](../../releases) から APK をダウンロードして入れてください。
「提供元不明のアプリ」のインストールを許可する必要があります。

## はじめかた

実機の ROM が無くても、Neko Project II 内蔵の互換 BIOS で起動します。
ゲストの OS（MS-DOS など）は、フロッピーか HDD のイメージで用意してください。

1. アプリを起動し、「MENU」→「FDD1」または「HDD1」を選びます。
2. 「端末のファイルを直接開く」で、端末に置いたイメージを選びます。
3. HDD を変えたときは、メニューの案内に従ってリセットします。

## 画面とメニュー

画面の下半分はソフトキーボードです。上の段の「MENU」「SAVE」「LOAD」で、メニュー・ステートセーブ・ステートロードを開きます。

| メニューの項目 | 内容 |
|---|---|
| FDD1・FDD2 | フロッピーの挿入・取り出し |
| HDD1・HDD2 | IDE（SASI）の HDD。変更はリセット後に有効 |
| SCSI HDD… | SCSI の HDD（#0〜#3）。変更はリセット後に有効 |
| CD-ROM | CD-ROM の挿入・取り出し（すぐに反映） |
| 新しいディスクイメージを作る… | 空の FDD・HDD イメージを作る |
| ステートセーブ・ステートロード | 4 つのスロットに保存・読み込み |
| リセット | PC をリセットする |
| 詳細設定（np2 内蔵メニュー） | Neko Project II 本来の設定画面 |
| ファイル管理 | 作業フォルダを端末の「ファイル」で開く |
| 設定 | マウスの速さ、キーボードの高さなど |

## ディスクイメージ

イメージの入れ方は2通りです。

- **端末のファイルを直接開く**: 端末のファイル（ダウンロードフォルダなど）をそのまま使います。書き込みも元のファイルに反映されます。一度開いたものはメニューの履歴に残ります。
- **端末から取り込む（コピー）**: アプリの作業フォルダにコピーして使います。

同じイメージを2つのドライブに入れることはできません（イメージが壊れるため）。
使用中のイメージは、ファイル管理から書き換え・削除・名前の変更ができません。

### 対応している形式

| 種類 | 形式（拡張子） |
|---|---|
| FDD | D88（.d88 .88d .d98 .98d）、FDI（.fdi）、ベタ（.xdf .hdm .dup .2hd .tfd .flp .img）、DCP/DCU（.dcp .dcu）、NFD（.nfd）、Virtual98（.fdd）、BKDSK（.hdb など） |
| HDD（IDE） | .thd、.nhd、.hdi、.slh、.vhd（VirtualPC の固定・可変） |
| HDD（SCSI） | .hdd、.nhd、.hdi、.hdn・.hds（RaSCSI）、.vhd |
| CD-ROM | .iso、生イメージ（.bin .img）、.cue + .bin、.ccd・.cdm + .img、.mds + .mdf |

SCSI のディスクをつなぐと、SCSI BIOS（D2000h〜D5FFFh）が現れます。ゲスト側で EMM386 などの UMB の範囲を固定で設定していると、ぶつかることがあります。そのときはこの範囲を UMB から外してください。

## CD-ROM

CD-ROM ドライブは、IDE のセカンダリ・マスターにつながっています（PC-9821 構成）。

- **.iso・生イメージ**: そのまま選びます。
- **目次ファイルと本体に分かれた形式**: ファイルを選ぶ画面で、2つを一緒に選びます（長押しで複数選択）。目次ファイルだけを選んだときは、本体を選ぶように案内が出ます。
  - .cue と .bin（.cue に書かれた FILE の名前）
  - .ccd・.cdm と、同じ名前の .img
  - .mds と、同じ名前の .mdf
- 音楽トラック（CD-DA）は、.cue と .ccd で再生できます。トラックごとに別のファイルになっている .cue（複数の FILE、WAVE）は使えません。1 つの .bin にまとめたものを使ってください。

### ゲスト側の設定例（MS-DOS 6.2）

CONFIG.SYS に次の2行を書きます。

```
DEVICE=NECCDD.SYS /D:CD101
LASTDRIVE=Z
```

起動後に、次のコマンドで CD-ROM がドライブ Q: になります。

```
MSCDEX /D:CD101 /L:Q
```

## ホストドライブ

アプリの作業フォルダにある `HOSTDRV` フォルダを、DOS からドライブとして読み書きできます。ディスクイメージを作らずに、Android と PC-98 の間でファイルを受け渡せます。

1. 「MENU」→「設定」で「ホストドライブを使う」をオンにします（DOS から書き込むときは「書き込みを許可」も）。作業フォルダに `HOSTDRV` フォルダができます。
2. Neko Project II のユーティリティディスク `np2tool.d88` を用意して FDD に入れます（このアプリには入っていません。[Neko Project 21/W のダウンロードページ](https://simk98.github.io/np21w/download.html) などから入手してください）。
3. DOS で `HOSTDRV.COM` を常駐させます。例えば FDD がドライブ E: で、G: に割り当てるときは次のとおりです。CONFIG.SYS の `LASTDRIVE=Z` が要ります。

```
E:HOSTDRV G
```

`HOSTDRV` フォルダの中身は、端末の「ファイル」アプリの「Neko Project II for Android」→ `HOSTDRV` から出し入れできます。

- 設定のオン・オフを切り替えたら、ゲストをリセットしてください（オフにすると、常駐した HOSTDRV.COM からは使えなくなります）。
- DOS からは、ファイルの読み取り・新規作成・上書きができます。ファイルの削除・名前の変更・フォルダの作成はできません。
- DOS からは 8.3 形式の名前で見えます。長い名前は切り詰められます（`LongFileName.text` → `LONGFILE.TEX`）。切り詰めると同じ名前になるファイルが複数あるときは、そのうち1つだけが見え、DOS からの上書きもその1つに効きます。大事なファイルは、DOS から書き込む前に名前を 8.3 に収めておいてください。
- Android 側でコピーしている最中のファイルには、DOS から触らないでください（作業中のファイル名が DOS から見えることがあります）。

## ステートセーブとレジューム

- **ステートセーブ・ロード**: そのときの状態を 4 つのスロットに保存し、あとで戻せます。
- **レジューム**: アプリがバックグラウンドに移るとき、状態を自動で保存し、次の起動で続きから始めます。

ステートには、セーブしたときのディスクのパスも保存されます。ロードすると、ディスクはセーブしたときのものに切り替わり、HDD の設定もそれに合わせて変わります。

セーブのあとでディスクが書き換えられていると、確認が出ます。

> そのままロードすると、ゲストのファイルシステムが壊れるおそれがあります。ふつうはキャンセル（レジュームの場合は「レジュームせずに起動」）を選んでください。

ディスクが見つからないとき、HDD が今つながっているものと違うときも、何が変わるかを示す確認が出ます。

## ファイル管理と設定

- **ファイル管理**: アプリの作業フォルダ（np2.cfg・ステート・取り込んだイメージの置き場所）を、端末の「ファイル」画面で開きます。ほかのアプリのファイル選択画面からも「Neko Project II for Android」として見えます。
  - np2.cfg を編集した内容は、次にアプリを起動したときに反映されます。編集する前にアプリを終了しておくのが確実です。
- **設定**: マウスの速さ、フルキーボードの高さ（横画面）、ソフトキーの不透明度、右の余白のキー（横画面）、キーを押したときの振動、[ホストドライブ](#ホストドライブ)。

## 既知の制限

| 項目 | 状況 |
|---|---|
| SD カード上のイメージを直接開く | 未確認（対応端末が無いため） |
| NFD r1 の特殊読み込み（READ DIAGNOSTIC など） | 未確認 |
| .hdn（RaSCSI）の中身のあるイメージ | 未確認（.hds と同じ処理） |
| N88-BASIC 形式の BKDSK（.HDB・.DDB） | 形式の判定だけ確認済み |
| サブチャンネル付き CD（.mds + .mdf の 2448 バイト/セクタ）の音楽トラック | 未確認（データトラックは確認済み） |
| .nrg（Nero） | 未対応 |
